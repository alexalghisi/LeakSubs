## Getting started

Requires Node 22 or newer.

```bash
npm install
npm run dev          # http://localhost:5182
```

Cancel the **World Class** ghost membership. Watch the yearly leak drop. Contact sits under the window.

```bash
npm run typecheck
npm run lint
npm run format:check
npm run test
npm run e2e
npm run build
```
